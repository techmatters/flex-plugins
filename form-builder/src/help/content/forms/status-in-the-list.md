Each helpline's line on the Forms page says where its draft is:

- **No changes yet**: nobody has changed anything.
- **In progress**: someone has made changes that haven't been sent for review.
- **Submitted for review by** someone: it's with the Aselo team.

In orange underneath, what's still open: *open questions*, *changes needed*, or things that *need attention*. Open the draft to see them; each has an icon on its form and field.
