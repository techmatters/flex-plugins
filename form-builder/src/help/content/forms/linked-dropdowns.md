Linked dropdowns are two or more dropdowns where each one's answers depend on the answer above, like province, then district, then municipality.

1. Open the form and click **+ Add a field**.
2. Choose **Linked dropdowns**.
3. Say what the first dropdown asks. It can be **A new question** or **A dropdown that's already on this form**.
4. Name each level below it (e.g. *District*, then *Municipality*).
5. Fill in the answers: by hand, or from a spreadsheet. With a spreadsheet, copy the cells in Excel or Google Sheets (one column per level) and paste them. If the first row has column names, say so, so it isn't imported as an answer.
6. Check them with **Try it out in Aselo**: choose a province and see its districts.

> **Tip:** it's easiest to prepare the list in a spreadsheet first, one row per lowest-level answer, e.g. *Province A, District 1, Municipality X*.
