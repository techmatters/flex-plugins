Each rule is a card, in order: the first one that fits a contact takes it.

1. Open Routing and the workflow (each workflow is a tab).
2. Click a rule's card to open it.
3. **Task conditions** say which contacts it takes, e.g. channel is chat and language is Spanish.
4. **Worker conditions** say where they go, in order: the queue, the skills counselors need, who to prefer, the priority, and what happens if nobody takes it in time.
5. Drag cards to change their order. **Common rules** adds the ones most helplines have in one click.
6. Check it with **Test a task**, and look at **Check** for rules that can never match.

> If you're not sure how to write a rule, describe it in plain words in a comment for the Aselo team.
